SocialFlow

Privacy Policy

Last updated: August 2026

SocialFlow is a personal, single-user tool for managing posts on Facebook Pages that the account owner administers. It is not a public service — access is restricted to one owner account, and it does not collect or process data on behalf of any other person or business.

What data this app handles

  • Facebook Page access tokens — used only to publish, preview, and manage posts on Pages the owner administers.
  • Post content — captions and images the owner creates or uploads, stored so drafts and posting history can be reviewed later.
  • Gemini API key — used only to call Google's Gemini API on the owner's behalf, to generate post ideas, captions, and images.
  • Basic account info — an email address and display name used to sign in.

How this data is stored

All data is stored in a private database (Firebase Firestore) tied to the owner's individual account, protected by access rules so only that account can read or write it. Tokens and API keys are never committed to source code or shared with any third party.

How this data is used

Facebook tokens and the Gemini API key are used exclusively to make requests directly from the owner's own browser to Facebook's Graph API and Google's Gemini API, in order to publish posts and generate content the owner explicitly requests. No data is sold, shared, or used for advertising, analytics, or any purpose beyond operating this personal tool.

Third-party services

This app connects to:

  • Meta / Facebook Graph API — to publish and manage posts on the owner's own Pages.
  • Google Gemini API — to generate captions, content ideas, and images.
  • Firebase (Google) — for authentication and data storage.

Each service's own privacy policy governs how they handle data sent to them.

Data retention and deletion

Data is retained for as long as the owner's account exists. Facebook tokens and the Gemini API key can be removed at any time from the app's Settings page. The owner can also revoke Facebook access at any time from Facebook's Business Integrations settings , and revoke or regenerate the Gemini key at any time from Google AI Studio.

Contact

Questions about this policy can be directed to the app owner via the contact details on file with the associated Facebook Developer account.
